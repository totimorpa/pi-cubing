# Changelog

## 0.1.3

- Improve help dialog layout: one shortcut per line with colored keys and lighter descriptions.

## 0.1.2

- Add `h` help dialog with controls.
- Add `i` solve-info dialog with scramble, date, time, penalty, and rating.
- Make delete prompt for `y`/`n` confirmation.

## 0.1.1

- Make stopwatch digits tabular/fixed-width so centiseconds do not make the timer wiggle.
- Use a fixed `SS.CC` display under one minute, e.g. `04.25`, for better readability while solving.

## 0.1.0

- Initial release with `/cubing`, scramble generation, timer overlay, averages, ratings, local persistence, and solve editing.
